# GRIFF

Русскоязычный тренажёр для возвращения к электрогитаре и басу: интерактивный гриф со звуком, минорная пентатоника, открытые и пауэр-аккорды, рекомендации переходов, план на 30 минут и метроном.

Node.js 22+.

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

`npm run build` — production-сборка, `npm run preview` — её локальная проверка. Звук синтезируется в браузере после взаимодействия с интерфейсом. Карточки исполнителей выбирают упражнения по приёмам; это не табулатуры конкретных песен. Таймер и отметки упражнений хранятся в текущей сессии страницы.

## GitHub Pages

Сайт размещается по адресу `https://nbscom.github.io/griff/` после успешной публикации. В Settings → Pages выберите Source → GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует приложение при каждом push в `main`; можно запустить его вручную из Actions. Vite использует базовый путь `/griff/`.
