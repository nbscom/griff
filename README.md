# GRIFF

Тренажёр электрогитары и баса: USB-аудиовход, тюнер, метроном, аккорды, гриф и упражнения для соло.

## Запуск

Node.js 22+ (проверено на 24):

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

Базовый путь приложения — `/griff/`. `npm run build` создаёт `dist` и обновляет сгенерированные `index.html` и `assets/` в корне, `npm run preview -- --port 5174` запускает production-сборку.

## Инструменты и строй

Гитара: стандарт, Drop D, Eb и Drop C♯ (Drop D на полтона вниз), 24 лада. Бас: 4 струны, 20 ладов, стандарт, Drop D и Eb. На басу вместо аккордов доступны интервалы и гаммы. 42 гитарных аккорда: основные, септаккорды, sus и все 12 пауэр-аккордов. Названия аккордов соответствуют реальному звучанию; в пониженных строях аппликатуры пересчитываются. В Drop D / Drop C♯ пауэр-аккорды на 6–5–4 струнах берутся одним пальцем.

Упражнения: пентатоника, смена струн, легато, бенды и фразировка; для баса — отдельные рисунки. Пример показывает целевые высоты, а не тембр и артикуляцию реальной гитары. Восьмые, общий темп с метрономом. В 6/8 BPM обозначает четверть с точкой (три восьмые). Темп 40–220, акцент на начало такта и дополнительный акцент на 4-й восьмой в 6/8.

## Mooer / аудиовход

Подключить процессор по USB, открыть приложение по HTTPS (либо localhost для разработки), нажать «Подключить», разрешить доступ к микрофону и выбрать Mooer в списке входов. На macOS может также понадобиться системное разрешение на микрофон для браузера. Для настройки включить чистый звук без delay, pitch shifting и сильной дисторсии; играть одну открытую струну.

Захват: `getUserMedia`, `echoCancellation: false`, `noiseSuppression: false`, `autoGainControl: false`. AudioContext запускается с `latencyHint: interactive`. Анализ выполняется локально в AudioWorklet алгоритмом YIN, кадр 8192 сэмпла, шаг 2048. Частоты от 30 Гц; проверены E1 и D1. Окно анализа добавляет около 171 мс при 48 кГц для устойчивого определения баса — это не заявленная задержка мониторинга. Вход не выводится в динамики, не записывается и не отправляется на сервер. «Отключить» освобождает устройство.

Автоопределение струны выбирает ближайшую по абсолютной частоте открытую струну выбранного строя. Можно выбрать струну вручную. Шкала ±50 центов, допуск ±5; показание цифрами не ограничено шкалой.

## Проверки

```sh
npm test
npm run build
npm run preview -- --port 5174
# В другом терминале; нужен установленный Chromium:
npm run test:browser
```

`CHROMIUM_PATH` задаёт путь к Chromium. `TEST_URL` позволяет проверить опубликованную версию. Браузерный тест использует виртуальный вход E1: проверяет запрос getUserMedia, реальные настройки захваченной дорожки, production AudioWorklet, тюнер, отсутствие сигнала, выбор устройства, запрет микрофона, планирование метронома, упражнения и мобильную ширину. Скриншоты — в игнорируемом `test-results/`. Это не заменяет проверку реального Mooer на MacBook / Safari.

## GitHub Pages

Сайт: https://nbscom.github.io/griff/. Текущий источник Pages — `main:/`. Исходный HTML хранится в `web/index.html`; корневой `index.html` и `assets/` генерируются командой `npm run build` и коммитятся вместе с кодом. Не редактируйте эти выходные файлы вручную. `.nojekyll` отключает обработку Jekyll. Workflow `.github/workflows/pages.yml` также запускает тесты и публикует идентичную сборку из `dist` при push в `main` или вручную из Actions. Оба способа публикации содержат одинаковые файлы приложения. Аудиовход запрашивается по нажатию кнопки; разрешения управляются браузером.

## Новые инструменты практики

- **Проверить себя:** поиск ноты в выбранном диапазоне/на струне; ответ кликом или через USB. Для USB нужна одна нота в указанной октаве, в пределах ±35 центов. Правильность первой попытки и среднее время ответа сохраняются локально; исправление ошибки не создаёт второй результат. Тренировка не оценивает ритм и полифонические аккорды.
- **Слух:** интервалы по очереди или одновременно, распознавание мажора, минора, пауэр-аккорда и доминантсептаккорда. Ноты синтезируются без чужих записей; ответы проверяются после прослушивания.
- **Аккомпанемент:** редактируемая последовательность до 16 аккордов, 1–4 такта на аккорд, перестановка, заготовки и до 12 избранных последовательностей. Партии ударных, баса и аккордов отключаются отдельно; на басу его партия изначально выключена. Общий темп и размер с метрономом. Запуск аккомпанемента останавливает упражнение/метроном, чтобы не накладывать независимые ритмы; запуск упражнений или слухового задания останавливает аккомпанемент.
- **A–B:** номера первой и последней нот фрагмента, отсчёт одного такта, прибавление 5 BPM после каждых трёх кругов с пределом 220. Показан фактический темп воспроизведения; это счётчик прослушанных кругов, не автоматическая оценка чистоты игры.
- **Гриф:** подсветка услышанной через USB высоты, отображение ступеней, блюзовая гамма, мажорная пентатоника, дорийский и миксолидийский лады.
- **Память браузера:** инструмент/строй/темп/размер, результаты заданий и избранное. Не требует аккаунта; при недоступном localStorage приложение продолжает работать и сообщает, если сохранение невозможно. Микрофон не подключается автоматически после перезагрузки.

Проверенные источники сравнения и границы реализации: [docs/feature-comparison.md](docs/feature-comparison.md).

### Бас: интервалы и гаммы

При выборе басового интервала прямо под его кнопками появляется четырёхструнный гриф на 20 ладов. На узком экране масштаб и прокрутка автоматически показывают ближайшие позиции тоники и цели. Видны конкретные высоты выбранной тоники и цели (например, E1 → E2). В режиме интервалов гриф показывает позиции именно этих высот: тоника зелёная, цель янтарная; октава в режиме ступеней обозначена `8`, а не `1`. Гаммы показывают все позиции своих звуков на 20 ладах, а кнопка прослушивания играет одну октаву. Выбор новой тоники, режима, строя или инструмента отменяет предыдущий звуковой пример, включая ещё не начавшиеся ноты.

`npm run test:bass` — отдельная браузерная проверка басового раздела, включая три строя, состав и звук гамм, интервалы, отмену старого звука, синхронизацию тоники и мобильную версию. Этот тест также входит в `npm run test:browser`.

### Интервал от любой выбранной ноты · гитара и бас

Общий раздел «Ноты, интервалы и гаммы» доступен для обоих инструментов. Нажмите любую позицию на встроенном грифе, затем выберите один из 13 интервалов (от примы до октавы) и направление вверх/вниз. Точная исходная позиция отмечена светлым контуром; её высота и октава сохраняются при смене интервала. Янтарные позиции — реальные варианты целевой высоты. Нажатие любой позиции, включая цель, выбирает новую исходную ноту.

На полном грифе «Ноты под пальцами» тот же сценарий доступен через список «Интервал от выбранной ноты». Выбор синхронизируется между двумя грифами. За пределами диапазона цель не переносится в другую октаву: приложение показывает сообщение и предлагает сменить направление или исходную ноту. При смене инструмента/строя позиция сбрасывается; выбор тоники по названию также возвращает исходную высоту в нижний регистр инструмента.

`npm run test:intervals` проверяет выбор позиции, сохранение регистра, все 13 интервалов, оба направления, все 7 строев, верхнюю/нижнюю границы грифа, связь с полным грифом и мобильную версию. Входит в `npm run test:browser`.
