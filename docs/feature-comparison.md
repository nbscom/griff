# Сравнение и выбранные функции · 27.10.2026

Изучены публичные README проектов через GitHub API. Это сравнение описанных функций, а не результаты личного использования приложений. Сайты Yousician, Songsterr, Fretastic и musictheory.net в этой среде отвечают отказом сетевого прокси, поэтому их текущие функции не используются как проверенное основание.

| Приложение / источник | Описанные функции | Чего не было в GRIFF / реализация |
| --- | --- | --- |
| [Fretboard Trainer](https://github.com/David-Yang258/FretBoard-Trainer#readme) | Поиск позиций и нот, диапазон струн/ладов, обратная связь, локальная статистика | Задания с диапазоном и выбранной струной, ответы на грифе или через USB, правильность первой попытки и время ответа в этом браузере |
| [Fretboard Trainer (web)](https://github.com/damassi/fretboard-trainer#readme) | Запоминание грифа | Интерактивный опрос вместо только справочного грифа |
| [Guitar Trainer](https://github.com/vitaliy-petrenko/guitar-trainer#readme) | Слушает микрофон и отображает ноту на виртуальном грифе | Подсветка реально сыгранной ноты с учётом выбранного строя, передача YIN в задания |
| [Guitar Ear Training](https://github.com/hieple19/guitar-ear-training#readme) | Распознавание одиночного аккорда и последовательностей | Одиночные аккорды и интервалы на слух с проверкой ответа и повторным прослушиванием; распознавание последовательностей пока не добавлено |
| [Bass Guitar Trainer](https://github.com/dkijania/bassguitartrainer#readme) | Ноты на грифе, метроном, драм-машина | Синтезированные ударные и отключаемые партии баса/аккордов для совместной игры |
| [Band in a Jar](https://github.com/calippo/band-in-a-jar#readme) | Пользовательская последовательность, темп, повторы, MIDI-экспорт | Редактор последовательностей и тактов, циклический аккомпанемент, сохранение избранного. MIDI-экспорт не добавлен |
| [Guitar Trainer (jwagner)](https://github.com/jwagner/guitarTrainer#readme) | Рабочие тюнер и метроном; лупер заявлен как нереализованный | Тюнер и метроном уже были в GRIFF; не считаем запись/лупер реализованными у источника |

Дополнительно для существующих упражнений GRIFF: выбор A–B-фрагмента по нотам, отсчёт перед стартом, автоматическое увеличение темпа по кругам. Это собственное расширение, не утверждение о проверенных функциях недоступного Songsterr.

Реализация собственная. Код, записи, табулатуры и дизайн сторонних приложений не копировались. Аккомпанемент и слуховые задания синтезируются локально. Запись живого сигнала не выполняется; результаты и избранное хранятся только в localStorage этого браузера.
